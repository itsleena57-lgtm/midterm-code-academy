# BrightPath Tech Academy

## About My Project

BrightPath Tech Academy is a simple educational website created using HTML5 and CSS3. It provides information about technology courses, student benefits and academy contact details.

## 1. Which HTML elements did you use to structure the website?

I used header, nav, section, div, h1, h2, h3, p, a and footer elements to structure my website.

## 2. How did you arrange the course cards?

I used CSS Grid to arrange six course cards. On desktop, three cards appear in one row. On tablet, two cards appear in one row, and on mobile, cards appear one by one.

## 3. Which CSS property did you find most useful, and why?

I found the display: grid property most useful because it helped me arrange the course cards and other sections properly.

## 4. What problem did you face during development, and how did you solve it?

I faced a problem with adjusting the website layout for different screen sizes. I solved it by using CSS media queries for desktop, tablet and mobile screens.

## 5. How did you make your website responsive?

I used CSS media queries with different screen widths. I adjusted the course cards, navigation, About section and Student Benefits section to fit different devices.
